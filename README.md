# FUTURE_CS_01

This repository contains documented vulnerability assessments and exploit demonstrations conducted during the Cyber Security Internship at Future Interns.
Task 01: Exploitation of Broken Access Control (IDOR) in OWASP Juice Shop using Burp Suite.
• 	Identified unauthorized access via basket ID manipulation
• 	Captured HTTP traffic and response evidence
• 	Proposed mitigation strategies aligned with OWASP Top 10 (A01:2021)
Tools used: Burp Suite, Kali Linux, OWASP Juice Shop
